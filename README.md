
## main

Этот проект содержит программы на языке C++, которые реализуют различные функции, связанные со строками.

## Ветка main
В ветке main хранится файл main.cpp, который содержит реализацию функции приведения всех букв в строке к верхнему и нижнему регистру.

## Ветка palindrom
В ветке palindrom хранится файл palindrom.cpp, который содержит реализацию функции проверки того, является ли строка палиндромом.

## Ветка znaki
В ветке znaki хранится файл znaki.cpp, который содержит реализацию функции удаления всех знаков препинания и служебных символов (кроме пробела) из строки.
